## 微信标题栏连续最小化（2026-11-09）

将已映射顶层窗口的 `WM_CHANGE_STATE/IconicState` 转发给 Niri 后，同时向 X11 客户端
写入 `WM_STATE=IconicState`；恢复时沿用现有焦点处理写回 `NormalState`。否则 Qt 未收到
中间状态，恢复后仍缓存“已最小化”，第二次点击标题栏按钮便不再发出请求。
可见性和恢复仍由本机支持最小化的 Niri 管理，不取消映射 X11 窗口，也不改动 Dock。

隔离集成测试验证同一窗口连续三轮最小化／恢复，检查请求次数、ICCCM 状态及窗口仍映射。
修复前测试在 `NormalState != IconicState` 处失败，修复后通过。完整检查包含 88 项库测试和
38 项集成用例；文件剪贴板用例首次超时，单独复测通过。此补丁仅部署到本机微信的 `:4`
桥接，保留现有输入法、高分屏与文件剪贴板方案。

本机部署并重启微信后，用户已确认连续三次“标题栏最小化 → Dock 恢复”均正常。
